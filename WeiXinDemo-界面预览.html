与「仿美团外卖」完全对齐的工程配置：Gradle 8.2 + AGP 8.1.4 + compileSdk 34 / minSdk 21 / targetSdk 34，Java 17。
下面的界面全部按工程里的真实布局还原，头像与配图直接引用 res/drawable-nodpi 下生成好的占位图，文案与 assets/weixin.json 一致。
新增能力：改联系人备注、改我的昵称、改头像（16 宫格 + 从手机相册选照片）、 20+ 组关键词自动回复（你好 / 吃饭了吗 / 晚安 / 在吗 / 谢谢 / 生日快乐…，同一句还会随机换说法）、 局域网在线聊天（电脑跑一个 Java 服务端，两台设备同一 WiFi 互发消息）。
本轮新增：发朋友圈动态（文字 + 相册最多 9 图，落 SQLite）、 点赞 / 评论 / 回复某人（自己的动态和评论可长按删除）、 和联系人玩小游戏（猜拳 / 猜数字 / 翻牌配对，战绩一键发到聊天）。
这轮完善：全屏图片查看器（左右滑动翻页、双指缩放、双击放大、单击隐藏顶栏）、 聊天直接发图片（相册选图 → 压缩落盘 → 气泡里显示缩略图，点开看大图）、 聊天「⋯」菜单（看联系人资料 / 清空聊天记录）、 战绩长期保存（猜拳胜负、猜数字最少次数、翻牌最少步数，游戏大厅可查看和清空）、 猜数字加区间收窄提示、翻牌加计时与新纪录提示。
最新一轮：图片真实化（17 个好友头像换真人照片风、朋友圈配图换生活实拍风、封面换山川湖景）、 微信红包（橙色红包气泡 + 金色「開」拆红包动画，聊到「红包」对方也发一个）、 语音消息（按住说话，气泡里喇叭 + 秒数，点一下播放动画）、 长按菜单（复制 / 撤回 2 分钟内消息 / 删除，撤回显示灰色系统提示）。

㉘ 设置页（昵称 / 微信号 / 性别 / 地区都能改，存 SharedPreferences 全 App 生效）

在线聊天是怎么跑起来的：电脑上运行一个极简 Java 服务端（ChatServer，纯 JDK，无第三方库）， 它按昵称维护一张转发表；手机 App 里的 ChatClient 用 Socket 连上去，一条消息一行 JSON、 以换行分帧。A 发消息 → 服务端按「收件人昵称」找到 B 的连接 → 转发给 B，B 的界面立刻刷新。
两台设备连同一个 WiFi，登录页填电脑的局域网 IP（服务端启动时会打印）即可；不填就直接走本地演示模式。

朋友圈的数据是怎么存的：动态与评论都在 SQLite（t_moment / t_moment_comment）， 第一次打开朋友圈时把 assets/weixin.json 里的示例动态导入一次，之后发的动态、点的赞、 写的评论都会保存，退出 App 再进来还在。配图从相册导入后会压缩到最长边 1080 存进 files/moments/，数据库里只记绝对路径。

小游戏：三个玩法都是本地即时演算（对手随机出拳 / 随机答案 / 洗牌），不依赖服务器， 所以不联网也能玩；从聊天页「+」进入时会自动带上当前聊天对象，结束后可以把比分作为一条普通聊天消息发出去。 战绩写在 SharedPreferences（game_stats），猜拳记胜负，猜数字和翻牌只记最好成绩。

图片相关：朋友圈配图和聊天图片都压缩到最长边 1080 后存进 files/moments/， 数据库里只记绝对路径。聊天消息表从 v3 升到 v4 时补了一列 type （0 文字 / 1 图片），v5 又补了 status（撤回）和 extra 两列， 红包是 type=2（content 存 JSON：留言 / 金额 / 已领）、语音是 type=3（content 存秒数）， 升级都用 ALTER TABLE 加列，老聊天记录不受影响。
看大图统一走 PhotoViewerActivity：它内部是一个自写的 ZoomImageView， 用 Matrix + ScaleGestureDetector 实现缩放和拖动，没有引第三方图片库。

红包 / 语音 / 撤回：发红包约 2 秒后对方会自动拆开并道谢，聊天里提到「红包」对方也会发一个； 语音是「按住说话」的模拟实现（只有时长没有真录音），点气泡有播放动画； 撤回只允许撤自己 2 分钟内发的消息，撤回后整行变灰色系统提示，会话列表按「最后一条未撤回的消息」重新显示。

转账 / 拍一拍 / 表情 / 收藏 / 设置（v6）：转账是 type=4 的橙色卡片（content 存 JSON：金额 / 说明 / 收款状态）， 对方点卡片确认收款后卡片变「已收款」，演示模式里我发的转账会被对方自动收下并道谢； 拍一拍是 type=5 的居中灰字系统消息，双击聊天页头像触发； 表情面板从底部弹出，96 个 Unicode 表情点击插入输入框； 长按消息可以「收藏」，存进新表 t_favorite（DB v6 新增），从「我-收藏」查看、长按删除； 「我-设置」打开独立设置页，昵称 / 微信号 / 性别 / 地区都能改（存 SharedPreferences），全 App 即时生效。 界面细节上：头像全部改成微信的圆角方形（约 4dp 圆角），聊天气泡圆角收窄到 4dp， 会话列表加了从头像右侧开始的分割线，搜索框换成浅灰圆角，朋友圈图标换成微信的蓝黄双色圈。
