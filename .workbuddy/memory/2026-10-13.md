# 2026-10-13 工作日志

## WeiXinDemo 教学：面向初学者的代码导读

用户定位为「安卓 + Java 初学者」，诉求不是改代码，而是**学会看懂这个项目、最终能独立做项目**。

**产出**：`WeiXinDemo/代码导读-新手学习手册.md`（约 300 行），结构：
0. 一句话总纲（任何 Android 代码只有界面/数据/通道三种角色）
1. 工程目录地图（java 各子包职责 + res 各目录 + assets + Manifest）
2. Java 知识落点对照表（类/继承/接口/内部类/静态/单例/集合/泛型/异常/线程/回调/字符串 → 对应本项目哪个文件）
3. Android 概念落点（四大组件、Activity 生命周期三步用法、Intent 传参、列表三件套 + ViewHolder、Manifest/launcher）
4. **三条必须打通的调用链**（A: Tab 切换 Fragment add+show/hide；B: 列表数据→Adapter→getView→displayName；C: 发送消息跨设备全链路）
5. 两种持久化（SharedPreferences vs SQLite + Cursor/ContentValues/占位符/内存缓存）
6. 通用方法：读陌生项目五步法
7. 四阶段学习路线 + 练手任务清单（③阶段 4 个改本项目任务；④阶段待办清单 App 等）
8. 调试三板斧（Logcat/断点/Toast）+ 本项目踩过的 6 个坑 + 编译环境
附录 A 类清单速查、附录 B 建议阅读顺序

**配套可视化**：3 张 SVG（三层架构总览、消息完整链路、四阶段路线图）。

**教学法要点（可复用）**：讲代码不按文件顺序讲，按「调用链」讲；每个知识点先给「为什么存在」（如 Handler 是为了"子线程不能碰界面"），再给落点；每个阶段给明确验收标准。
