## WeiXinDemo：朋友圈互动 + 小游戏（本轮新增）

### 1. 朋友圈从「只读」改成可发可互动

- **数据层**：`WeixinDbHelper` 升到 v3，新增 `t_moment`（name/avatar/content/images JSON/time/ts/mine/likes JSON）
  与 `t_moment_comment`（moment_id/user/reply_to/text/ts/mine）；`onUpgrade` 仍只跑 `onCreate`（全 IF NOT EXISTS）。
- **MomentDao**：`ensureSeed()` 首次把 assets 的 moments 导入（SharedPreferences 标记，删光也不复活）；
  `queryAll()` 一次查全部评论再按 moment_id 分发；`insert / deleteMoment / toggleLike / addComment / deleteComment / formatTime`。
  点赞用 `MomentBean.ME_TAG = "@me"` 占位，显示时替换成当前昵称，改昵称不会丢赞。
- **MomentBean** 扩展 `ts / mine / CommentBean(id, replyTo, mine)`。
- **发动态**：`PublishMomentActivity` + `activity_publish_moment.xml`；`ACTION_GET_CONTENT` + `EXTRA_ALLOW_MULTIPLE`，
  多选取 ClipData、单选取 getData；`MomentPhotoStore` 采样解码 + EXIF 转正 + 最长边 1080 / 质量 88 存 `files/moments/`；
  未发表退出时 `onDestroy` 清理已导入图片。
- **圈内互动**：`item_moment.xml` 重写（FlowLayout 九宫格 + 时间/评论/点赞行 + 评论容器）；
  `MomentAdapter` 支持点赞态、单图 200dp、多图三列、评论一条一个 TextView（点击回复 / 长按删除）、点图看大图；
  `MomentsActivity` 实现 5 个回调（赞、评论、删评论、看图、长按删动态），底部评论 Dialog（`dialog_comment.xml`）。
- **布局技巧**：FlowLayout 来自美团工程（`view/FlowLayout.java`），子 View 用 `ViewGroup.LayoutParams`（不是 FlowLayout.LayoutParams）。

### 2. 小游戏

- `GameActivity`（`activity_game.xml`）：猜拳（7 帧抖动后定格，`(a-b+3)%3` 判定）、猜数字（1~100，7 次）、
  翻牌（4×2，GridLayout 动态 8 张，650ms 回翻 + memoryBusy 防连点）；三个玩法共用比分，`gameIndex` 可直入。
- `GameLobbyActivity`（`activity_game_lobby.xml`）：发现页「游戏」入口，三张卡片 → 选联系人 → 带 chatName/avatar/chatId 进游戏。
- 聊天页 `ivAdd` 改为弹 `dialog_chat_more.xml`（相册/拍摄/视频/位置 + 小游戏），小游戏是真入口，其余 Toast。
- 「把战绩发到聊天」= `ChatManager.send(chatId, "【小游戏·猜拳】我 3 : 2 张三，再来一局？")`；
  冷启动从大厅进入时 `loadChatsThenMatch()` 补一次 `ChatManager.init`。
- 所有 Handler 延时在 `onDestroy` 清空。

### 踩坑

- `android:selected="true"` 是非法 XML 属性（只能代码 `setSelected`），AAPT 报 `attribute android:selected not found`。
- 自定义 ViewGroup（FlowLayout）没有自己的 LayoutParams 类，写 `FlowLayout.LayoutParams` 直接编译不过。
- ListView 有 header 时 `setEmptyView` 永远不生效，空态要手动控制显示。

## WeiXinDemo：第二轮完善（图片 + 战绩 + 聊天菜单）

### 1. 全屏图片查看器

- `view/ZoomImageView.java`：自写，`scaleType=MATRIX` + 基准矩阵（`onSizeChanged` 里按 `min(vw/dw, vh/dh)` 算并居中）。
  `ScaleGestureDetector` 缩放（上限 3×，焦点为两指中心）、`GestureDetector.onScroll` 拖动（仅在 >1× 生效）、
  双击 1× ↔ 2.5×、`onFling`（速度 >600 且横向占优）翻页、`onSingleTapConfirmed` 隐藏顶栏；
  每次手势结束 `clampMatrix()`：小图居中、大图不留黑边。
- `activity/PhotoViewerActivity.java` + `activity_photo_viewer.xml`：extras `ArrayList<String> images` + `index`；
  本地路径 `MomentPhotoStore.loadFull()`（不采样、不进 LruCache），资源图走 `WeixinDataUtils.getDrawableId`；页码 `n / m`。
- MomementsActivity 旧的 Dialog 看图删除，改为把整条动态的 images 传过去，支持九宫格左右翻页。
- 坑：`setImageDrawable` 会被父类构造函数提前调用，重写时必须用 `inited` 标志挡住未初始化字段。

### 2. 聊天图片消息

- DB 升 v4：`t_message` 加 `type INTEGER NOT NULL DEFAULT 0`。
  `onUpgrade` 先 `onCreate`（IF NOT EXISTS）再 `ALTER TABLE ... ADD COLUMN type`，包 try/catch 吞「列已存在」。
- `MsgBean.type`（0 文字 / 1 图片）+ `isImage()` + `summary()`（"[图片]"）；
  `MessageDao` 读写 type；`ChatManager.sendImage(chatId, path)`（LAN 模式只发 "[图片]" 文本）。
- `item_msg_left/right.xml` 各加 150dp `iv_picture`，`MsgAdapter` 按 type 切文字/图片，点图进查看器。
- `ChatActivity`：「+」→ 相册走 `ACTION_GET_CONTENT`，`MomentPhotoStore.importFromUri` 在后台线程，完成后 `sendImage` + 刷新；
  本地演示模式会顺带安排一条自动回复。
- 坑：图片消息不能走 Socket（没做文件协议），否则对方收到本机路径打不开。

### 3. 战绩持久化 + 小游戏增强

- `utils/GameStats.java`：SharedPreferences `game_stats`，键 `rps_win/rps_lose/rps_draw`、`guess_best`、`memory_best`；
