## 黑马《Android 移动开发基础案例教程》第 12 章 —— 仿美团外卖综合项目

在 `MeiTuanWaiMai/` 下从零建出了完整的 Android 工程（Gradle 8.2 + AGP 8.1.4、compileSdk 34、minSdk 21、Java 17）。

**产出规模**：18 个 Java 类、13 个布局、61 个 drawable（含脚本生成的占位图）、6 家店铺 / 36 道菜的 assets/shop.json、README、界面预览 HTML。

**包结构**：`cn.itcast.order` 下 activity(5) / adapter(5) / bean(2) / utils(4) / view(2)。

**关键设计决策**：
- 购物车状态集中在静态类 `CartManager`（两个 LinkedHashMap 存 FoodBean + 数量），避免 Intent 序列化副本导致数量不一致；`switchShop(shopId)` 实现换店自动清空。
- 自定义 `ShopListView` 重写 `onMeasure()`（AT_MOST + Integer.MAX_VALUE>>2）解决 ListView 嵌 ScrollView 只显示一条的问题。
- 用户同名的 `MenuAdapter.OnMenuListener` 与 `CartAdapter.OnCartChangedListener` 都有 `onCartChanged()`，**同一类不能同时 implements 这两个接口**（方法签名相同会冲突），改为只 implements MenuAdapter 的回调，CartAdapter 用匿名内部类传入。这是个容易踩的坑。
- 购物车弹窗：全屏 PopupWindow（内部手写半透明遮罩 + 靠底内容），`showAtLocation(..., Gravity.BOTTOM, 0, dp(56))` 向上偏移底部栏高度，保持底部购物车栏可见。
- 数据源双通道：默认读 assets/shop.json，`Constant.USE_SERVER=true` 切到 HttpURLConnection 请求 Tomcat（对应教材 12.3）。

**环境情况（重要）**：本机 `D:\java21` 有 JDK 21，但**没有安装 Android SDK / Gradle / Android Studio**，因此无法在此机编译验证 APK，代码正确性只能靠静态校验。

**验证手段**：写了两个 Python 静态检查脚本（放在 `_build/`）：
- `check_refs.py`：校验 Java 的 R.xxx.yyy 与 XML 的 @drawable/@color/@string/@style 是否都有定义、Java 用到的 id 是否在布局中声明、shop.json 引用的图片名是否存在。结果：全部通过。
- `check_java.py`：校验类名与文件名一致、import 指向的类存在、跨类静态调用的方法存在、括号配对、接口方法齐全。结果：全部通过。
注意脚本要排除 `@android:` 前缀的框架资源和带点的样式名（如 Theme.Order），否则误报。

**gradle-wrapper.jar**：raw.githubusercontent.com 和 jsdelivr 都拉不到（403/超时），最后从 `https://gitee.com/mirrors/gradle/raw/v8.2.0/gradle/wrapper/gradle-wrapper.jar` 下载成功（63375 字节，校验含 GradleWrapperMain.class）。以后需要 Gradle 相关文件优先试 gitee 镜像。

## 仿微信 WeiXinDemo（与美团项目同一套工程配置）

在 `WeiXinDemo/` 下建出第二个 Android 工程：Gradle 8.2 + AGP 8.1.4 + compileSdk/targetSdk 34 + minSdk 21 + Java 17，
包名 `cn.itcast.weixin`，依赖 appcompat 1.6.1 + fragment 1.3.6。

**产出规模**：24 个 Java 类、22 个布局、78 个 drawable（矢量图标 + shape 背景）、`drawable-nodpi` 下 26 张 jpg 占位图、assets/weixin.json、README、界面预览 HTML。

**包结构**：activity(4: Main/Chat/Moments/UserInfo) / adapter(5) / fragment(4) / bean(5) / utils(4) / view(2)。

**关键设计**：
- `ChatManager` 静态类作会话与消息的内存数据中心，微信 Tab 列表 / 聊天页 / Tab 红点共用一份数据，发完消息返回自动同步最后一条消息与未读红点。
- `MainActivity` 用 Fragment 的 add + show/hide（不用 replace）切 4 个 Tab，避免来回切重建页面。
- `CircleImageView` 用 BitmapShader 裁圆；`SideIndexBar` 自定义 View 回调字母，`ContactAdapter.getPositionForLetter()` 换算 ListView 行号。
- **踩坑**：JSON 里图片名写成 `avatar1.jpg`，而资源名不能带点，`getIdentifier("avatar1.jpg", ...)` 返回 0 → 头像不显示。已在 `WeiXinDataUtils.getDrawableId()` 里先 `lastIndexOf('.')` 去扩展名。
- 占位图放 `res/drawable-nodpi`（不是 drawable），矢量图标放 drawable。

**✅ 已在本机实机编译通过**（BUILD SUCCESSFUL in 1m 8s，app-debug.apk 3.28 MB）。本机编译环境（重要，后续复用）：

## WeiXinDemo 进阶改造：改备注 / 改昵称 / 局域网在线聊天

用户要求「保留现有功能」的前提下再加三项能力，经确认走**局域网 Socket 直连** + **简易登录页 + SQLite 存记录**路线。

**三层结构**：界面层（Activity/Fragment/Adapter 基本不动）／数据层（ChatManager + SQLite DAO）／通道层（AppPrefs + ChatClient → Socket → ChatServer）。

**新增/重写文件**：
- `WeixinApp.java`（Application，预热 JSON 全局 Context）
- `utils/AppPrefs.java`：SharedPreferences 存 my_nick/my_avatar/server_host/server_port/logged_in/lan_mode，getMyNick()/getMyAvatar() 回落到 WeixinDataUtils.getLocalUser()，DEFAULT_PORT=8888，isLanMode() 控制在线/离线。
- `db/WeixinDbHelper.java`（单例，建 t_message/t_remark/t_chat 三表）、`db/MessageDao.java`、`db/RemarkDao.java`（内存缓存 + SQLite，displayName(name) 备注优先；备注删空即删记录）、`db/ExtraChatDao.java`（在线新建会话，EXTRA_ID_START=1000）。
- `utils/ChatClient.java`：单例后台线程 Socket 连接 + 断线重连；**用 volatile int generation（代次）防双连竞态**（connect 时 ++generation 传入 loop，循环内校验）；sendLine/builtJson（清换行）；handleLine 分发到 ChatManager.receiveRemote / notifyNotice。
- `ChatActivity` / `UserInfoActivity` / `MeFragment` / `LoginActivity` 重写；`ChatAdapter`/`ContactAdapter`/`ContactsFragment`/`ChatsFragment`/`MainActivity`/`MomentsActivity` 联动改造。

**显示联动**：`RemarkDao.displayName(name)` 备注优先；`AppPrefs.getMyNick()` 昵称回落。会话列表/联系人列表/聊天页标题统一走这条链路，改完备注 onResume 自动重套。

**监听器机制**：`ChatManager.OnChatChangedListener`（主线程回调）实现收到远端消息自动刷新会话列表/聊天页；`ChatClient.Listener` 统一处理连接状态与服务器通知。ChatActivity 的监听里加 `refreshing` 重入锁（clearUnread 也会触发回调，不加会自调）。

**协议**：一行一条 JSON，用 `\n` 分帧（避免粘包/拆包），`BufferedReader.readLine()` 读取。

**服务端** `ChatServer/`（独立 Java SE 工程，**纯 JDK 无第三方库**）：`ChatServer.java`（ServerSocket + CachedThreadPool + ConcurrentHashMap<昵称,ClientHandler> 转发表，printStartupInfo 打印局域网 IP，手写极简 jsonGet/jsonEscape）、`TestClient.java`（联调）。已 javac 编译并实跑，验证「张三→李思思 转发成功、不在线提示正确」。
- 启动踩坑：PowerShell 里 `java -Dfile.encoding=UTF-8` 会被当成类路径参数（ClassNotFoundException .../encoding=UTF-8），要写成带引号的 `"-Dfile.encoding=UTF-8"`。

**保留离线演示**：LoginActivity 不勾「连服务器」→ 走 assets/weixin.json + 模拟回复（ChatManager.receive + AUTO_REPLY_DELAY）。

**验证**：`_build/check_weixin.py` 0 问题（32 Java 类、24 布局、80 drawable、61 字符串、66 布局 id、58 Java id）；`gradle.bat assembleDebug --offline` **BUILD SUCCESSFUL**，app-debug.apk 3.38 MB。README 完全重写，界面预览 HTML 补了登录页/备注编辑/在线聊天三个新界面。

**在线聊天使用步骤**：电脑跑 ChatServer（打印本机局域网 IP）→ 两台设备连同 WiFi → 登录页填该 IP:8888 → 双方昵称互发。昵称即身份，服务端按昵称转发。

**遗留**：ChatServer 与 App 均未做鉴权（班级演示够用）；真机验证需用户在设备上自行安装 APK 测试。
