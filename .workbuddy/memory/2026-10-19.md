## WeiXinDemo 增量功能：改好友头像 + 关键词自动回复

在不改动原有功能的前提下，给仿微信加了两个能力，编译通过（app-debug.apk 3.40 MB，14:29 产出）。

### 1. 改好友头像
- **存储**：`WeixinDbHelper` 版本 1→2，新增 `t_avatar(contact_name, avatar)`。
  所有建表语句改成 `CREATE TABLE IF NOT EXISTS`，`onUpgrade()` 直接调 `onCreate(db)`，
  **旧聊天记录与备注不丢**，只补新表。
- **DAO**：新增 `db/AvatarDao.java`，与 RemarkDao 同套路（HashMap 内存缓存 + upsert）。
  提供 `POOL`（avatar1~avatar16）、`normalize()`（去 .jpg 扩展名）、`displayAvatar(name, fallback)`。
  约定：**无记录 = 用 assets 原头像**，所以"恢复默认"就是删记录。
- **界面**：`UserInfoActivity` 新增「头像」行（`item_avatar_row.xml`，含 36dp 圆形预览）。
  点开 `dialog_avatar_picker.xml`（GridView 4 列）+ `AvatarPickerAdapter`，选中项套 `bg_avatar_selected.xml` 绿环。
  「恢复默认」按钮必须在 `dialog.show()` 之后用 `getButton(BUTTON_NEUTRAL)` 重设监听，
  否则 AlertDialog 默认"点完即关"的行为会生效。
- **联动**：ChatAdapter / ContactAdapter / MsgAdapter / UserInfoActivity / ChatActivity 全部改走
  `AvatarDao.displayAvatar()`；改完调 `ChatManager.notifyChanged(chatId)`（**该方法的可见性从 private 改为 public**）
  让不在前台的会话列表也重画。MsgAdapter 构造函数改为 `(context, otherName, otherAvatar, myAvatar)`，新增 `setOtherAvatar()`。

### 2. 关键词自动回复
- 新增 `utils/AutoReplyRules.java`，规则是二维数组，按顺序 `contains` 匹配：
  `吃饭了吗→吃了`、`你喜欢谁→我是同性恋`、`你好→你好`；未命中返回 null，回落到原有随机回复。
- `ChatActivity`：`scheduleAutoReply()` 改为接收输入内容；新增 `pendingReply` 字段；
  `autoReplyTask` 优先用命中规则的回复。
- 触发条件从「非局域网模式」改为「**真连上服务器才不回复**」(`AppPrefs.isLanMode() && ChatClient.get().isConnected()`)，
  这样一个人演示时即使勾了在线模式但没连上，关键词回复仍然生效。

- `gradle.bat assembleDebug --offline`：BUILD SUCCESSFUL in 23s
- README 补了 t_avatar 表、关键词规则章节（新增「九」并把原九/十顺延为十/十一）
- 界面预览 HTML 新增 ⑩ 选择头像、⑪ 关键词回复两屏

## 追加：头像支持从相册选 + 自动回复话术扩充（14:45 编译通过，APK 3.25 MB）

### 1. 相册选头像（好友 + 我自己都支持）
- 新增 `utils/AvatarStore.java`：头像的「进站/出站」统一工具。
  - `importFromUri(context, uri, key)`：先 `inJustDecodeBounds` 读尺寸算采样率，再解码、
    居中裁成正方形（Canvas 垫白底，避免透明 PNG 压 JPEG 变黑）、缩到 512、JPEG 90，
    存到 `files/avatars/avatar_<hash>_<ts>.jpg`，返回绝对路径。
  - `apply(view, avatar, fallbackRes)`：路径→解码 Bitmap，资源名→setImageResource，
    中间有 8MB `LruCache`（`sizeOf` 用 `getByteCount`）。
  - `deleteIfLocal()`：换头像时删旧文件，目录不膨胀。
- `AvatarDao`：`normalize()` 遇到以 `/` 开头的绝对路径原样返回（不能去扩展名）；
  `save()` 里替换/恢复默认时删除旧本地文件。
- 相册入口用 `ACTION_GET_CONTENT` + `image/*` + `CATEGORY_OPENABLE`，**不需要存储权限**；
  解码放后台线程，回主线程刷新。
- 好友：`UserInfoActivity` 的对话框加「从相册选择」（`dialog_avatar_picker.xml` 新增 `tv_pick_gallery`）。
- 我的：`MeFragment` 点个人卡片改成底部菜单（修改昵称 / 从相册更换头像 / 恢复默认头像）；
  `onActivityResult` 里导入并写 `AppPrefs.setMyAvatar(path)`。
- 所有显示点改走 `AvatarStore.apply`：ChatAdapter、ContactAdapter、MsgAdapter、
  UserInfoActivity、MeFragment、MomentsActivity；MsgAdapter 的 myAvatar 改为可变 + `setMyAvatar()`，
  `ChatActivity.onResume` 同步我自己的头像。

### 2. 自动回复话术扩充
- `AutoReplyRules` 从 3 条扩到 20+ 组：吃饭、恋爱、打招呼、早午晚安、道谢、道别、
  生日、天气、夸人、日常闲聊等。
- 回复内容支持 `|` 分隔多个候选，`pick()` 随机挑一句；仍按数组顺序 `contains` 匹配，
  长关键词必须排在短的前面（如「你好吗」在「你好」前）。

### 验证
- `check_weixin.py`：0 问题（layout=27、drawable=81、string=74、id=71/63）
- `gradle.bat assembleDebug --offline`：BUILD SUCCESSFUL in 13s，APK 3,444,508 字节（14:59）
- 补了 EXIF 方向处理：`ExifInterface(InputStream)` 仅 API 24+，低版本跳过；读 TAG_ORIENTATION 后 Matrix 转正再裁剪
- README 更新：功能表、结构图（加 AvatarStore）、t_avatar 注释、第八节头像出口、第九节规则示例
- 预览 HTML 更新：⑩ 加「从相册选择」、⑪ 加「在吗」话术、新增 ⑫ 我页资料菜单

## 新建 MilkTeaDemo 奶茶点单项目（编译通过，APK 3.56 MB，16:02 产出）

按仿美团外卖的同一套工程配置（Gradle 8.2 / AGP 8.1.4 / compileSdk 34 / JDK 17）从零做一个奶茶店点单 App。

### 工程与素材
- 目录 `MilkTeaDemo/`，包名 `cn.itcast.milktea`，applicationId 同名，minSdk 21。
- 12 张商品图用 ImageGen 生成（11 杯饮品/小食 + 1 张横幅），`_build/prep_images.py` 用 Pillow
  裁掉右下角水印、居中裁方、压成 600×600 JPEG，输出到 `res/drawable-nodpi/`。
- mipmap 与 gradle wrapper 从 MeiTuanWaiMai 复制，保证工程可直接 Open。
- 依赖只有 `androidx.appcompat:1.6.1`，不引入第三方 UI 库。

### 代码分层
- 数据层：`assets/milktea.json`（门店/分类/商品/规格/满减）→ `GoodsDataUtils`（静态缓存解析）
  → bean（Shop/Category/Goods/Option/CartItem/Order/OrderItem）→ `CartManager`（LinkedHashMap 静态单例）
  → `PriceUtils`（BigDecimal 算钱）。
- 购物车 key = `goodsId|规格文本`，同商品不同规格分行；数量不存 Item，列表数字每次 `getCountByGoods()` 现查。
- 持久化：`OrderDbHelper`（t_order / t_order_item）+ `OrderDao`（insert 用事务，金额用 TEXT 存 BigDecimal）。
- 界面：MainActivity + Home/Orders/Mine 三个 Fragment（add + show/hide，不用 replace）；
  GoodsDetail / Cart / ConfirmOrder / Pay / PaySuccess / OrderDetail / Search 七个 Activity；
  GoodsAdapter / CartAdapter / OrderAdapter；自定义 `FlowLayout` 做规格自动换行。
- 订单状态机：0 待支付 → 1 制作中 → 2 已完成 / 3 已取消，列表按钮与详情文案都由状态驱动。
- 购物车在「提交订单写库成功」时清空（不是支付时），这样从订单列表补付旧订单不会清掉当前新选的东西；
  PayActivity 返回键跳主界面「订单」Tab（MainActivity 支持 `tab` extra + onNewIntent）。

### 验证
- 新增 `_build/check_milktea.py`（复用 check_weixin.py 思路，改包名与 JSON 字段）：
  0 问题，layout=18、drawable=48、string=52、id=141/136。
- `gradle.bat assembleDebug --offline`：BUILD SUCCESSFUL in 37s（增量 6s），APK 3,733,129 字节。
- 文档：`MilkTeaDemo/README.md`（功能/结构/四条链路/JSON 与建表/8 个设计点/编译/改数据指南）；
  根目录 `MilkTeaDemo-界面预览.html`（8 屏：首页、详情、购物车、确认订单、收银台、支付成功、订单列表、我的）。

## 仿美团外卖升级 v2.0：补齐 13 项正式功能（编译通过，APK 3.76 MB，17:26 产出）

在原教材项目（5 个 Activity）基础上增量扩展，**原有链路与文件结构保留**，新增能力如下。

### 1. 首页与导航
- 底部导航 `layout_bottom_nav.xml`（首页/订单/我的），用 `res/color/nav_tint.xml` 状态选择器
  实现图标/文字选中变橙；每个 Activity 单独 include，切换用 `FLAG_ACTIVITY_CLEAR_TOP|SINGLE_TOP` + finish，避免栈堆叠。
- 首页改为橙色头部（定位 + 搜索框）+ `GridLayout` 4×2 分类频道（8 个圆形彩色入口，
  `bg_cat_1..8.xml` 批量脚本生成）+ 排序栏 + 快捷筛选（满减/免配送费）+ 店铺列表。
- 排序/筛选纯本地对 `allShops` 处理，`displayShops` 与原始顺序分离；标题实时显示结果数。

### 2. 搜索与分类
- `SearchActivity`：同一页承载「普通搜索」与「分类频道」两种模式（intent 传 category/categoryName，空则为普通模式）。
- 历史（SP 存 `|` 分隔，最多 10 条）+ 热门词 + `FlowLayout` 自动换行标签 + 空结果提示。
- 关键词同时匹配店铺名、分类、店内菜品名；分类模式先 `ShopRepository.byCategory` 再关键词过滤。

### 3. 店铺详情
- 标题栏右侧 `tv_right` 改成收藏按钮（`AppPrefs.toggleFavorite`），进入时按 SP 回显「收藏/已收藏」。
- 店铺信息区新增评价入口，显示 `评分 · 128+id*7 条评价`；`ReviewListActivity` 用 `ReviewDataUtils`
  按店铺 id 稳定生成 8 条评价（同一店铺每次内容一致）。

### 4. 下单链路
- `OrderActivity` 扩展为完整结算页：地址（跳 `AddressListActivity`，select_mode 回传 AddressBean，需 Serializable）、
  送达时间（AlertDialog 三选一，写 "HH:mm 送达"）、优惠券（`CouponActivity` 回传 discount/title）、
  备注（6 个快捷标签追加到 EditText，去重）、餐具 0~10。
- 金额：`goods + distribution - discount`，全程 BigDecimal 两位小数；默认 `CouponUtils.bestCoupon()` 自动选最优券。
- 提交订单先在 SQLite 建 `status=0` 订单再跳支付；支付成功才 `updateStatus(1)` 并清空购物车。
- `PaySuccessActivity`：查看订单 / 返回首页（CLEAR_TOP）。

### 5. 订单中心
- `OrderDbHelper` 单表 `t_order`，商品明细用 `items_json` 存快照（不需要联表，历史订单不受改价影响）。
- `OrderDao`：insert / queryById / queryAll / queryByStatus / countByStatus / updateStatus。
- `OrderListActivity` 四个 Tab（全部 -1 / 待支付 0 / 配送中 1 / 已完成 2），支持 `tab` extra 直达。
- 条目动作按状态驱动：待支付=取消/去支付；配送中=取消/查看详情；已完成或已取消=再来一单。
- 「再来一单」：`ShopRepository.findById` → `CartManager.switchShop` → 按 foodId 回填数量 → 直接进店铺详情。

### 6. 我的 / 地址 / 优惠券 / 收藏
- `MineActivity`：橙色渐变头（`bg_mine_header.xml`）、昵称点击修改（SP + 头像首字联动）、
  订单数量统计、地址/收藏/优惠券/关于入口。
- 地址：SP 存 JSON 数组（`AppPrefs`），列表页支持选择模式与编辑；编辑页支持姓名/手机/详细地址/默认/删除，
  删默认地址时自动把第一条设为默认；首次进入 `ensureDefaultAddress()` 写入示例地址。
- 优惠券：`CouponUtils` 正则解析 feature 的「满X减Y」，另加平台券「满50减8」；
  `CouponActivity` 有结算选择与浏览两种模式（无 shop extra = 浏览）。
- 收藏：`AppPrefs` 存 id 集合，`FavoriteActivity` 从 `ShopRepository.getFavorites()` 还原。

### 7. 数据扩充

### 踩坑
- **`android:selected="true"` 不是合法 XML 属性**，AAPT 直接报 `attribute android:selected not found`；
  selected 只能在 Java 里 `setSelected()`。改完记得在 initView 末尾主动调一次 `updateSortState()`。
- 批量 Edit 时 `old_string` 多带了一行，把 `setOnItemClickListener(new ...() {` 整行删掉，
  导致后续代码孤立；幸好下一次编译前 Read 复查发现并补回。**改完关键方法要 Read 回看**。
- `AddressBean` 走 `getSerializableExtra` 必须 implements Serializable。
- PowerShell 执行 gradle 时 stderr 的 SDK 警告会被当成 NativeCommandError，TaskOutput 显示 failed，
  实际以日志里的 `BUILD SUCCESSFUL` 为准。
